# GA4 Streaming Demo

This project demonstrates a **near-real-time GA4 event streaming pipeline** with BigQuery, dbt, and Cloud Functions, along with a dashboard visualization (Looker Studio / Streamlit).

---

## **Project Overview**

- **Streaming events:** Sample GA4-like events generated by a Cloud Function.
- **Pub/Sub:** Events are published to a Cloud Pub/Sub topic.
- **BigQuery:** Raw events ingested into `stg_events`, deduplicated in `int_events`, and aggregated in `mart_attribution`.
- **dbt:** 
  - Handles incremental processing, deduplication, and mart-level aggregation.
  - Provides tests, documentation, and materializations.
- **Visualization:** Metrics such as First vs Last attribution, 14-day time series, and channel breakdown visualized in Looker Studio / Metabase / Streamlit.
